How to add devices

  1. Create a scan group below: a name plus targets (a subnet like 10.200.200.0/24 or single IPs).
  2. In Run live scan, tick the group(s) to scan.
  3. Enter the SSH username and password (and enable secret if needed), then press Start scan. Reachable switches are added to Devices automatically.
  4. Credentials are used once, held in memory only, and never stored. Only show commands are run.

No network access? Use Offline audit to upload a config backup instead.
